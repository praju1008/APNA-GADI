# APNA GADI 🚗⚡ — EV Rental Web Application

A full-stack Electric Vehicle (EV) rental platform built with React.js, enabling users to browse available vehicles, book rentals, and manage reservations through a clean, intuitive interface — with a dedicated admin dashboard for vehicle and booking management.

## 📌 About the Project

APNA GADI ("Our Vehicle" in Hindi) is an academic full-stack project simulating a real-world EV rental service. It was built to demonstrate end-to-end web development skills — from UI/UX design and routing to state management and responsive design.

Users can sign up, browse available electric vehicles, check details, and book rentals. Admins get a separate dashboard to manage vehicle listings and monitor bookings — replicating how a real rental business would operate online.

---

## ✨ Features

- 🔐 **Secure User Authentication** — Sign up / Login with protected routes
- 🚘 **Browse Vehicles** — View available EVs with details (model, pricing, availability)
- 📅 **Book Rentals** — Reserve a vehicle for a selected duration
- 🧑‍💼 **Admin Dashboard** — Add, edit, and manage vehicle listings and bookings
- 📱 **Mobile-First Responsive Design** — Fully usable across mobile, tablet, and desktop
- 🔄 **Dynamic State Management** — Smooth, real-time UI updates without full page reloads
- 🧭 **Client-Side Routing** — Seamless navigation via React Router

## ⚙️ Getting Started

### Prerequisites
- Node.js (v16 or later)
- npm or yarn

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/praju1008/APNA-GADI.git
cd APNA-GADI
```

2. **Install dependencies**
```bash
npm install
```

3. **Run the app**
```bash
npm start
```

4. **Open the app**
Visit `http://localhost:3000` in your browser.
